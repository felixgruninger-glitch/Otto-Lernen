# Otto lernt

Lernseite für Mathematik und Deutsch (Klasse 5–6). Keine externen Abhängigkeiten.

- `index.html` – Oberfläche
- `js/basis.js` – Hilfsfunktionen, Grafiken, Fehlertexte
- `js/mathe.js` – Fast Math (A1–A5) und Mathe-Level (B1–B9)
- `js/deutsch.js` – Grammatik, Rechtschreibung, Wortschatz, Lesen, Papier-Lückentexte (alle Texte selbst verfasst)
- `js/engine.js` – Methode: Schnelltest → Lernkarte → Musteraufgabe → Üben mit Mix → 🥈 → Check am nächsten Tag → 🏆 → Wiederholung nach 3/7/14/30/60 Tagen
